## Recent updates to watch

- **Stacked pull requests are generally available.** Break a large change into smaller, focused pull requests that you can review independently and merge together. Source: [GitHub Changelog, Oct 6, 2026](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available).
- **Local sandboxing for GitHub Copilot is generally available.** Commands that Copilot runs in the CLI, the Copilot app, and VS Code Agent Host sessions can run with restricted filesystem, network, and credential access. Source: [GitHub Changelog, Oct 7, 2026](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available).
- **GitHub Actions workflow lockfiles are in public preview.** Lock workflow dependencies to exact commits so a moved tag or branch can't change what runs. Source: [GitHub Changelog, Oct 14, 2026](https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview).
